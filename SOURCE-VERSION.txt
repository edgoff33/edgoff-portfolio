BUILD CHECKLIST - do all four, every rebuild
--------------------------------------------
1. Bump the VERSION line above. Scheme YYYY-MM-DD-x, letter increments
   for further builds the same day.
2. Move anything just built from NOT YET IN THIS VERSION into
   WHAT IS IN THIS VERSION, and leave "Nothing outstanding" if empty.
3. Update the Current section of Source_Zip_Version.md in project
   knowledge to the same version, with the same manifest.
4. Update Portfolio_Index.md - the piece's row, the sitemap count, and
   the Source version line at the top.

HOW TO CHECK A ZIP IS CURRENT
-----------------------------
1. Open SOURCE-VERSION.txt at the root of the unzipped folder.
2. Compare the VERSION line against the one recorded in Portfolio_Index.md.
3. If a zip has no SOURCE-VERSION.txt, it predates 2026-09-23 and is stale.

python3 build.py prints the version at the top of every build.
